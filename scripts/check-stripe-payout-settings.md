# How to Check Stripe Payout Settings

## Step-by-Step Guide

### 1. Go to Stripe Dashboard
- Visit: https://dashboard.stripe.com
- Make sure you're logged in

### 2. Navigate to Payout Settings
- Click **Settings** (gear icon in top right)
- Click **Payouts** in the left sidebar
- OR search for "payouts" in the search bar

### 3. Check Current Settings

You'll see:

**Payout Schedule:**
- [ ] Daily
- [ ] Weekly  
- [ ] Monthly
- [ ] Manual ← **This is what you want**

**Payout Details:**
- Minimum payout amount: $X.XX
- Payout delay: X days
- Bank account: [Your bank account]

### 4. Change to Manual (If Needed)

1. Click **Edit** or **Change schedule**
2. Select **Manual**
3. Click **Save**

### 5. Verify Bank Account

Check:
- Is this YOUR bank account?
- Is this the account you want to receive payouts?
- If not, add/change bank account

### 6. Check Recent Payouts

Go to **Payouts** → **All payouts** to see:
- Recent payouts
- Which charges were included
- Where money went

## What to Look For

### ✅ Good Setup
- Payout schedule: **Manual**
- Bank account: **Your account**
- Recent payouts: **Only when you initiated them**

### ❌ Problem Setup  
- Payout schedule: **Daily/Weekly/Monthly** ← This causes automatic payouts
- Recent payouts: **Automatic payouts every X days**

## After Changing to Manual

1. **Money will stay in Stripe balance**
2. **You can pay creators** (transfers will work)
3. **You manually withdraw** remaining balance when needed

## Need Help?

If you can't find the settings:
1. Search "payouts" in Stripe Dashboard
2. Go to Settings → Connect → Payouts (if using Connect)
3. Check Stripe Dashboard → Balance → Payouts tab
